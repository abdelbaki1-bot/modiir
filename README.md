# متجر MODiiR

موقع ثابت باستخدام HTML وCSS وJavaScript عادي، باتجاه RTL، دون إطار أو أدوات بناء.

## التشغيل

من داخل مجلد المشروع شغّل خادم ملفات محليًا:

```bash
python3 -m http.server 4173
```

ثم افتح `http://localhost:4173` في المتصفح. يمكن فتح `index.html` مباشرة، لكن تشغيل خادم محلي أفضل لتخزين المتصفح والصور.

## الإعدادات والبيانات

- في أعلى `app.js`: عدّل `STORE_NAME` و`PHONE` (اكتب الرقم الدولي دون علامة `+`) وروابط `SOCIAL_LINKS`.
- في `products.js`: عدّل أسماء المنتجات وأصنافها وصورها وحالة توفرها. الأسعار الحالية `null`، لذلك يظهر «اسأل عن السعر» ولا يُحسب مبلغ غير معروف. أضف السعر بالدينار الجزائري كرقم عند تأكيده.
- بيانات التوفر الحالية نموذجية ويجب مراجعتها قبل استخدام المتجر الحقيقي.
- الصور كلها ضمن `images/`، وتستخدم `fallback.svg` عند غياب صورة المنتج.

نموذج النشرة البريدية واجهة فقط إلى حين ربطه بخدمة اشتراك فعلية. لا يُرسل الطلب قبل تغيير رقم واتساب الافتراضي في أعلى `app.js`.
